# 怎么把“聊天”变成画布来源

## 1. 开两个真实聊天

每个场景两个聊天是故意分开的：它们代表不同时间点、不同立场，画布的价值就是把它们并列。

S1：

- 新会话 A，粘贴 `work-packages/S1-cache/01-chat-v1.md`，发送；
- 新会话 B，粘贴 `work-packages/S1-cache/02-chat-v2.md`，发送；
- 等两边都完成，最好各自有明确结论。

S2 / S3 同理。

## 2. 拖进画布

- 打开「画布」→ 素材库「对话」；
- 找到刚才两个会话，拖到画布（或点 +）；
- 从 `canvas-scenario/S1/inputs/` 把需求/日志/草案文件拖进画布；
- 画布会自动生成「新对话」节点。

## 3. 连线

- 从每个来源节点右侧圆点拖到「新对话」节点；
- 确认节点显示「N 个来源已连接」；
- 如果检查器打开导致画布太窄，先关掉检查器再拖；
- 顺序建议：聊天 A → 聊天 B → 文件 → 提示词。

## 4. 加任务要求

- 点「提示词」tab，把 `03-canvas-task.md` 的内容粘进去，加入画布并连线；
- 或者选中「新对话」节点，把任务写进「任务指令」。

## 5. 预览与创建

- 先点「预览上下文」，记录字符数/token；
- 检查来源是否齐全、顺序是否正确、文件是否内联；
- 点「创建并预填」，发送后按 `EXPECTED.md` 和 `RUBRIC.md` 打分。

## 6. 记录

把新对话的第一条回答整段复制到记录里，不要只写结论；同时记下预览统计和模式（摘要/摘要+片段）。
